# minishell

A simplified bash shell: prompt, history, pipes, redirections (`<` `>` `<<` `>>`), environment variables, signals and builtins (`echo cd pwd export unset env exit`).

## Build

```bash
make
```

## Usage

```bash
./minishell
```

Group project by **ekirsner** and **ktaouach**.

## Skills

Lexing and parsing, process creation (`fork`, `execve`, `waitpid`), pipes and file descriptors (`pipe`, `dup2`), redirections and heredoc, signal handling, environment management, teamwork with git.
